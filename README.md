# 메신저 기록 지킴이 · 배포

[최신 버전 다운로드](../../releases/latest)

GOE 메신저를 자동 백업하고 GOE 쪽지를 이 PC의 Brity 쪽지함에서 기존 기록과 함께 확인하는 Windows 프로그램입니다. 이 저장소에는 실행파일과 사용 안내만 게시합니다. 소스 코드는 별도의 비공개 저장소에서 관리합니다.

ZIP을 고정된 폴더에 모두 풀고 `메신저기록지킴이.exe`를 실행하세요. Python을 따로 설치할 필요가 없습니다. v0.5.0부터 프로그램이 새 버전을 확인하며, 업데이트 버튼을 누르면 백업과 설정을 유지한 채 교체 후 다시 실행합니다. 이전 버전 사용자는 v0.5.0을 한 번 직접 받아야 합니다.

백업은 GOE 로그인 후 한 번과 매시간 정각에 실행하며 최근 20개를 보관합니다. Brity에 처음 연결할 때와 프로그램을 업데이트할 때는 Brity를 트레이까지 완전히 종료하세요. GOE 쪽지는 이 PC에서만 읽기 전용으로 보이며 대화방·첨부파일 원본·서버 및 다른 기기 동기화는 지원하지 않습니다. 검증 버전은 GOE 7.0.2.11 / Brity 2.1.98이며 Brity 자체 업데이트는 별도입니다.

백업·쪽지·계정·인증정보는 이 저장소에 전송하지 않습니다. 자동 업데이트는 공개 배포 파일을 다운로드하며 GitHub 계정 로그인이 필요하지 않습니다. 오류가 나면 프로그램의 오류 진단 파일 기능을 사용하세요. 개인 백업이나 인증정보를 공개 이슈에 첨부하지 마세요.

이 프로그램은 GOE 또는 Brity의 공식 이관 도구가 아닙니다. Brity 연결 시 프로그램을 변경하며 원본 복구 자료는 로컬에 보관합니다. 중요한 GOE 백업은 별도 장치에도 보관하세요.
